Privacy Policy for Study Enforcer

Last updated: 13 June 2026

Study Enforcer ("the app") is a parental-control app that helps a parent limit a child's screen time on shared family devices and encourages educational quiz breaks. This policy explains what information the app handles and how.

1. Information the app collects

Study Enforcer does not require an account, does not collect personal information, and does not transmit any data to the app developer or to any analytics, advertising, or tracking service. All data described below stays on the device and is never uploaded anywhere.

  • Parental PIN — stored only as a SHA-256 hash on the device, used to unlock parent settings. It is never transmitted.
  • App usage / screen-time data — the app records, on the device only, which selected app(s) are in the foreground and for how long, in order to enforce time limits and daily quotas. This data is stored locally and is visible only to the parent inside the app's Activity Log.
  • Quiz settings and progress — grade level, subject, difficulty, badges earned, and quiz answer history are stored locally to personalise the questions shown to the child.

2. Accessibility Service usage

Study Enforcer uses Android's Accessibility Service API for one purpose only: to detect which app is currently in the foreground (its package name) so the app can measure screen time and trigger a quiz/block screen when a limit is reached. The service does not read screen content, text entered by the user, passwords, or any other on-screen information, and does not record audio or video.

3. Network access

The app makes network requests for one purpose: to download optional educational "content packs" (country-specific quiz question sets) from a static file hosting service (https://ioankokk17-sketch.github.io/studyenforcer-content). These requests do not include any personal data, device identifiers, or usage information — they simply fetch a public JSON file. If no content pack is downloaded, the app works fully offline using a bundled US question set.

4. Permissions the app requests, and why

  • Display over other apps (SYSTEM_ALERT_WINDOW) — to show the full-screen quiz/block overlay when a limit is reached.
  • Accessibility Service — see Section 2.
  • Ignore battery optimisations — so the enforcement service keeps running reliably in the background.
  • Notifications — to show a persistent status notification confirming the parental-control service is active.
  • Run at startup (RECEIVE_BOOT_COMPLETED) — so enforcement resumes automatically after the device restarts.
  • Query installed apps — so the parent can pick which apps to track from a list of installed apps on the device.

5. Children's privacy

Study Enforcer is designed to be configured by a parent or guardian and used on a shared family device. No personal information about a child is collected, stored remotely, or shared with third parties. All usage data remains on the device under the parent's control and can be cleared by uninstalling the app.

6. Data retention and deletion

All data is stored locally in the app's private storage. Uninstalling the app, or clearing its data via Android Settings, permanently deletes all stored information.
